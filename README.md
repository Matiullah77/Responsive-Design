## Introduction

This project demonstrates the basic principles of responsive web design using **HTML5, CSS3, CSS Grid, CSS Media Queries, and Bootstrap 5.3.3**.

The project contains four tasks. Each task demonstrates a different technique for creating responsive and user-friendly web pages that work on mobile, tablet, and desktop screen sizes.

---

## Task 1: Responsive Layout

This task demonstrates a responsive layout using **CSS Grid**.

Three boxes are placed inside a grid container. The layout changes depending on the screen size.

* **Mobile:** 1 column
* **Tablet:** 2 columns
* **Desktop:** 3 columns

CSS media queries are used to change the number of columns for different screen sizes.

## Task 2: Bootstrap Columns

This task demonstrates the **Bootstrap Grid System**.

Three responsive columns are created using Bootstrap classes.

* **Mobile:** 1 column
* **Tablet:** 2 columns
* **Desktop:** 3 columns

Bootstrap makes it easier to create responsive layouts without writing all the responsive CSS manually.

## Task 3: Bootstrap Navbar

This task demonstrates a **responsive Bootstrap navigation bar**.

The navbar contains:

* Home
* About
* Services
* Contact

On larger screens, the navigation links are displayed normally. On smaller screens, the links are placed inside a collapsible menu.

## Task 4: Responsive Portfolio

This task demonstrates a complete **responsive portfolio page** using Bootstrap and CSS.

The portfolio includes:

* Responsive navigation bar
* Projects section
* Four project cards
* About Me section
* Contact information
* Responsive sidebar
* Footer

The layout changes according to the screen size. On smaller screens, the content is arranged in a single column. On larger screens, the projects and sidebar are displayed side by side.
